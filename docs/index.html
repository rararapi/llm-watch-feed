Power Automate で Microsoft Teams に配信する手順

  1. Power Automate を開き 「新しいフロー」→「自動化クラウドフロー」 を選択
  2. トリガーとして 「RSS フィードに新しいフィードアイテムが発行されたとき」 を選択
  3. RSS フィードの URL に下記いずれかを入力（例: ）
  4. アクションに 「Microsoft Teams — メッセージを投稿する」 を追加
  5. メッセージ本文に フィードのタイトル / フィードのリンク / フィードの概要 などを設定
  6. フローを保存して有効化。以降、新着モデル情報が自動でTeamsに投稿されます。
